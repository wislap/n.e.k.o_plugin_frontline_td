# 星际开荒塔防：设计讨论与决策记录

> 本文档整理了前期概念设计讨论的过程、已经拍板的决策、尚未确认的建议、待定问题和下一步计划。
>
> 状态标记（两个维度）：
> - 决策状态：**【已定】**已经明确决定 / **【建议】**方向认可、细节未最终确认 / **【待定】**还没有决定 / **【搁置】**讨论过、明确不做或以后再说。
> - 实现状态：**【已实现】** / **【部分】** / **【未实现】**，可标注对应 ADR（如【已实现·ADR 0038】）。
> - 行内写法：`【已定｜未实现】` 表示决策已定但尚未实现。
>
> **本文的地位**：本文源自项目负责人早期的概念讨论，负责人本人并不认可其中全部内容。【已定】表示"当前采用"，不是不可动摇；有证据（实现成本、试玩、评估数据）时可以提出质疑，由负责人决定后更新本文或写 ADR。【建议】【待定】的条目不要自行当作需求实现，先确认。
>
> **原型现状**：当前可玩的是 proto_01 上的攻占模式——主基地、物流网、建造、小队指令（驻守 / 推进 / 集结）、导演集结波次与掠袭、3 个可反复争夺的据点、战争迷雾、攻破巢穴获胜（ADR 0034/0035/0038/0039）。与目标的差距：原型图 3 个据点，而非目标的一局 6–10 次攻占；无 Rogue 奖励（藏品、蓝图）；无局外成长；收益类型尚不丰富；内容仍是占位规模（一种炮塔、一种机器人、一种据点、三种怪物）。

## 1. 一句话概括

> **你是星际开荒公司的现场经理。在怪物横行的星球上，你建立供电补给网、修筑防线、指挥机器人小队，一步步推进前线、夺取据点，最终摧毁巢母，完成合同。**

核心体验：

> 你和怪物在几条进攻方向上拉锯。防御建筑守住阵地，小队推进、攻占据点；怪物集结反攻，你要侦察、预判，选择打断还是硬扛。整场战争的胜负，本质上是**补给网络的较量**。

和普通塔防最大的区别：**胜利条件是进攻（攻破敌军要塞），而不是撑过最后一波。**

## 3. 设计演进过程

记录几个关键转折点，方便以后回头理解为什么这样定。

### 3.1 起点：系统太多
最初的设想是"半自由建造 + 简单工厂 + 塔防 + 我方单位"。问题是四个系统都会抢玩家注意力，每个都做全就会又累又难做。

**结论**：不是砍掉想法，而是**合并和压缩**。保留想要的感觉，但让所有系统围绕同一个核心运转。

### 3.2 空间：从"一屏紧凑"到"大地图 + 明确方向"
讨论过两种空间形态：
- **紧凑型**（经典塔防：路一格、塔一格、一屏看完）：位置精确、节奏快，但装不下工厂和单位。
- **大地图型**（类似 Mindustry）：空间本身是资源，能容纳生产、物流和单位，但节奏慢，需要镜头移动。

**结论**：不做一屏之内的紧凑型。走中大型地图，敌人有明确的进攻方向。

后来进一步澄清：**不是"几条一格宽的固定轨道"**，而是像 Mindustry 那样自由寻路，由地形塑造战线。前线是一条较长的边界，而不是轨道上的一个点。

### 3.3 敌人：从"刷波次"到"集结反攻"
定期刷怪和"攻克敌军要塞"这个目标不一致。改为敌人集结、反攻，游戏就从"塔防刷波次"变成了"跟一个对手打仗"，节奏上自然形成攻守交替。

### 3.4 反滚雪球：引入补给系统
参考《钢铁雄心4》的补给系统：吃得到补给的单位才有战斗力。这个系统同时解决了多个问题：
- 双向的反滚雪球（冒进会变弱，被打回家门口反而变强）。
- 没有传送带之后"建筑位置不重要"的问题。
- 让攻占前哨有战略意义（前哨就是新的补给节点）。
- 创造新的战术目标（切断补给、保护补给线）。
- 让最终攻坚有一个自然的"准备阶段"。

**关键澄清**：补给中的运输车不是真实在跑的个体，而是"连接和运力"的抽象表现。建造、修复、前线部队、工厂运作都要接入补给网络才能工作。

### 3.5 镜头：2D 指挥 + 3D 观战
用户提出用于建造、指挥的 2D 平铺模式，再加一个用于观战的 3D 上帝视角主模式。讨论中补充的风险是：如果所有操作都只能在 2D 里做，玩家会一直待在 2D，3D 美术就白做了。因此建议做成同一个镜头的连续过渡。

### 3.6 题材：从多个方向收敛
比较过柴油朋克战争、微缩玩具战争、菌丝生物、魔法奇幻、工业远征 vs 异种生物。用户最终选择了**未来科技（机器人、无人机）vs 怪物，偏轻松有趣**。在此基础上比较了三个变体，当前首选是**星际开荒公司**。

## 4. 详细设计

### 4.1 空间与地图

**【已定】**
- 逻辑是 2D 网格，建筑占若干格。
- 中大型地图，一屏看不完。
- 敌人有明确的宏观进攻方向（比如主要从北边和东边来）。
- 单位自由寻路，没有预设轨道。
- 地形分为：可通行、带惩罚（减速等）、不可通行。

**【建议】**
- **"动线"的概念改为"进攻轴线"**：宏观上有方向，微观上由地形决定怎么走。
- **关键地形**：隘口、桥梁、山口、浅滩是天然的争夺点，战线的形态由地形塑造。
- **地形加成**：高地扩大射程和视野，森林提供隐蔽，河流后方易守难攻。这是 3D 视角真正发挥作用的地方。
- **地图设计的重要性大大提升**：地形就是关卡设计。好地图应该有几个清晰的主攻方向、若干关键隘口，以及一些可以绕路的次要通道。
- **前线**是一条真正的边界，即控制区域的轮廓，而不是轨道上的一个点。

### 4.2 镜头与视图

**【已定】**
- 2D 平铺视图用于建造和指挥。
- 3D 上帝视角作为观战的主视图。

**【建议】一个镜头，三个层级**
| 层级 | 镜头 | 内容 | 用途 |
|---|---|---|---|
| 观战视图（拉近） | 斜视角 3D 透视 | UI 最少 | 欣赏战斗、看细节 |
| 战术视图（中距离） | 正上方俯视，正交 | 网格、物流网、射程、前线、敌人预计路线等信息层；单位图标化 | 建造、指挥 |
| 战略视图（拉远） | 全图 | 只有图标和关键信息 | 看全局、调度小队 |

切换方式：
- 滚轮缩放时自然过渡【未实现：滚轮只在当前模式内缩放，不跨档位】。
- 快捷键在观战和战术视图之间一键切换【已实现：`Tab`（ADR 0048 部分取代 ADR 0028 原 `V` 键）】。
- **暂停或进入建造模式时，镜头自动俯下来并显示信息层；恢复运行后回到 3D。** 形成"暂停时规划，运行时观战"的节奏【已按 ADR 0048 演进为按模式切换：取消暂停自动切视角，改为进入建造（`F2`）/ 物流（`F3`）模式时自动切 2D 战术视角、回到指挥（`F1`）恢复 3D，并提供「视角锁定」开关】

细节注意：
1. 切换时保持空间连贯：镜头中心与水平旋转角 `yaw` 保持不变、平滑过渡；小地图始终保持北朝上并标出当前旋转视锥，随时按 `N` / `Home` 或点左上指北针归正北（已落地·ADR 0060）。
2. 2D 视图不另做一套美术，就是同一场景的正交俯视渲染加上信息层。
3. 地形高度在 2D 视图里要可读（等高线、明暗或颜色）。
4. 3D 视图里保留最关键的信息（补给不足警告、遭受攻击提示等）。
5. 3D 里最好也能做基础操作（选中小队、下简单指令），避免玩家因为"什么都做不了"而离开 3D。

### 4.3 单局结构与 Rogue

**【已定】**
- 一局约 30 分钟。
- 目标是攻破敌军要塞。
- 怪物持续施压（集结、反攻）。
- 每 2–5 分钟攻占一个前哨或资源点，一局大约 6–10 次攻占。
- 前哨和资源点有不同的性质和收益。
- 攻占之后战争迷雾往前推开。
- 可以暂停。

**【建议】Rogue 奖励**
- 局内攻占获得奖励，打完一局获得藏品、蓝图等奖励。
- 等原型验证核心玩法后再定。

**【建议】前哨类型**
- **资源点**：提升经济，比如解锁新配方或增加产量。
- **军事前哨**：解锁新的防御建筑、新的小队类型。
- **遗迹或宝库**：蓝图、藏品、强力的一次性奖励。
- **高危据点**：难打，回报也高。

**【建议】"Rogue 长在地图上"**
相当于把 Slay the Spire 的路线图放进地图空间里，往哪推、先打哪个点就是局内的构筑路线：
- 迷雾里的点只露出类型提示，不露细节；可以通过侦察，用时间或资源换信息。
- 拿下一个点会揭开相邻的点，形成分支。
- 敌人可以反扑一部分已占领的点，给"扩张太快"一个代价；但不要每个点都要守，否则压力失控。
- 前哨最好放在关键地形上（隘口、高地、桥头），攻占它们既有奖励，又能控制要道。
- 攻占的前哨同时成为**新的补给节点**。

**【建议】30 分钟的节奏曲线**
- 前期：守住，发展经济。
- 中期：推掉敌人前哨，扩大前线。
- 后期：把补给线修到要塞附近，集结主力，强攻要塞。
- 怪物强度随时间上涨，逼玩家去进攻，而不是一直龟缩。
- 越接近要塞，反攻越疯狂，最后一段是最激烈的攻坚战，自然形成高潮。

**【建议】暂停相关**
- 难度来源从手速转向决策质量，体验偏从容的指挥官。
- 因此可以放心做多方向同时施压。
- 配合调速（1x / 2x / 3x）：平静时加速，危急时暂停。

**【待定】局外**
- 无限模式（题材包装：加班），或者剧情模式（逐步揭开公司的秘密），或者两者都有。
- 原则：**先把单局做好玩，局外以后再选**。设计上让地图、前哨、怪物生态可配置、可组合，两种模式都能接上。
- 注意局外成长的力度，太强会让后面的局失去挑战。

### 4.4 敌人行为

**【已定】**
- 不是定期刷怪，而是集结、反攻。

**【已落地 · M4】**（实现细节见 [ADR 0035](../adr/0035-assault-mode-director-victory.md)）
- 导演控制者：90 s 首次集结于 `enemy_rally`，集结窗口 60 s（每完成一波 +10 s，上限 120 s）后按已存路线发动，目标取离集结点直线最近的敌对方建筑；波次消亡或出发 150 s 后进入 45 s 喘息。
- 集结可见性：集结点脉冲标记 + 兵力数 + 倒计时，集结路线画箭头，HUD 有横幅提示；波次出发后箭头保留至抵达。
- 怪物由 hive 生产建筑循环产出（无投入配方），产速随比赛时间阶梯提升；掠袭者单独编队袭扰物流节点。
- 【已实现·ADR 0038】每座据点派小队驻守（`garrison` 编制），其余怪物组成 `hive_guard` 守卫巢穴；波次目标优先取离集结点最近的已占领废墟或敌方据点。
- 打断集结、逐波难度、骚扰波等增量留待后续。

**【建议】可读性：看得到、来得及、能应对**
- **集结要可见**：集结点亮起，显示兵力规模、预计进攻方向、多久之后发动。
- **集结后显示预计进攻路线的箭头**（自由寻路之后这一点更重要）。
- **迷雾和侦察**：看不清的地方只能知道"有动静"，侦察后才知道规模和兵种。信息本身是一种资源。（迷雾【已实现·M5】，ADR 0039；"只露动静"的情报近似为集结小队始终可见的威胁情报）
- **可以打断集结**：主动出击打掉集结点，提前瓦解反攻。

**【建议】导演系统**
参考 Left 4 Dead 的 AI Director，由规则决定什么时候集结、往哪里打、打多大规模：
- 优先打玩家最弱的方向。
- 玩家推得太快就加大反扑。
- 随时间整体升级。
- 玩家刚打完硬仗时给喘息时间。

效果：看起来像一个有想法的对手，但完全可控、可平衡、可调难度。

**【建议】寻路策略**
- 大部分怪物只按地形和障碍物寻路，可预测，玩家可以设计"诱导路线"。
- 少数特殊怪物（侦察、突袭类）会寻找薄弱点，带来变化。
- 怪物会攻击挡路的障碍物，所以不存在"完全堵死道路"的问题。

**【建议】其他**
- 大规模反攻之外保留少量持续骚扰，让防线一直有事可做。
- 回弹机制：被压回时防守方有加成；怪物兵源被削减时会更保守；保底事件。

### 4.5 物流与补给（整个游戏的主轴）

**术语**：**物流网**是节点、连线和运输车的整体；**运力**是一条线路单位时间内能运多少；**货物**是物流网运送的一切东西（矿石、材料、能量、弹药）；**补给**指能量、弹药这些消耗品送达前线的情况。

**【已定】**
- 没有传送带，但有运输车和补给站。
- **运输车只代表连接和运力，不是真实在跑的个体**：车是计数，画面上的车队按实际流量生成。
- 运力的基本单位是**运输车**，不是人口；不设人口上限。
- **所有货物走同一套系统，传输瞬时，但每运一个单位都占用沿途线路的配额**，每秒结算一次。一次造几座塔基本无感；造多了开始排队，并明确显示"运不过来"。
- 中央仓库在主基地。建材、生产投料、能量、弹药从仓库出发；矿机产出、工厂产品运回仓库。
- 建造、修复、前线部队、工厂运作都要接入物流网才能工作。
- 补给站有本地储备；节点有血量，可被打击、修复、摧毁。

**网络模型【已定】**（详见 ADR 0025）
- **节点**：车站、补给站、主基地、占领的前哨。每个节点有两个距离：**连接距离**（和其他节点相连）和**服务距离**（就近服务建筑和部队）。车站连接距离大、服务距离小、车多；补给站反过来，车少、储备多；主基地两者兼有并带中央仓库。边界不清晰，定位清晰。
- **连线**：两个节点之间的地面路径长度不超过两者连接距离中较小的一个时自动连接。范围内两两相连，星形还是网状由玩家怎么放节点决定。连线沿地面路径走，地形和隘口影响物流。
- **运力配额**：车数 × 载量 × 车速 × 道路倍率 ÷ (2 × 路径长度)。路越长配额越低，这就是距离损耗。车站的车按需派到需要的线路上，不会闲着。正反方向各有一份配额，送货的车回程捎带矿石，入库不挤占前线。
- **路由全自动**：每批货走代价最低、仍有余量的路，主路满了自动绕路。玩家不规划车怎么走。
- **优先级**：**生命线**（作战单位和防御建筑的能量、弹药）固定最高；修复、建造、生产的顺序玩家可调；节点储备补充固定最低。同一优先级内先到先得。
- **被切断**：与仓库不连通的部分靠节点储备和单位自带的存量撑着，耗尽才断补给。

**消耗品【已定】**
- **能量**：单位和防御建筑的基础维护、激光类武器开火、工厂生产都消耗能量。主基地有基础能量产出（保底），发电厂是主要来源。
- **弹药**：动能类武器每次开火消耗。由弹药厂生产。
- **单位自带电池和弹匣**：在服务范围内会补充，离开就只能消耗自带的存量。小队因此有续航半径，推进太远会没电。
- 缺能量先减速，耗尽就停机（机器人趴下）；没弹药就哑火，但还能移动和撤退。

**道路【已定】**
- 默认都是土路，玩家不用自己铺路。
- 物流视图会高亮车最喜欢走的路（流量越大越粗越亮）和满载的路（发红）。点一下选中一条主干道，再点一下确认，就把它升级成道路，从仓库那头开始修，修好一段生效一段。
- **道路只改变线路运力（有效倍率），不改变线路的走向与连通**（实现约定见 ADR 0030）。
- 道路属于地面，节点被毁后重建，道路还在。MVP 只有一档升级，铁路以后再加。

**走廊拦截【已定】**
- 敌方单位（如突袭兵）停留在某条线路走廊内会持续削减该线的有效配额，削减量与在廊拦截强度成正比，可以削到零；离开即恢复（ADR 0030）。被拦截的线路在物流视图中标记。

**表现层**
- 运输车或无人机沿线移动，数量和密度根据实际流量生成，只是表现。
- 玩家一眼能看出哪条线繁忙、哪条线堵了。
- 在题材里可以表现为**成群飞行的无人机**，3D 观战中很好看。

**可读性（避免 HOI4 式的不透明）【已定】**
- 覆盖范围直接显示在地面上（3D 用地面光效或颜色）。
- 状态分档而不是显示具体数值，比如"满 / 不足 / 空"，单位头上一眼可见。
- 缺货原因分开显示：**仓库缺货**、**运力不足**（指出瓶颈线路）、**未接入**、**断线**。每条警告附带建议（加建车站、升级线路、增加产能）。
- 玩家需要做的决定只有：节点放在哪里、升级哪条主干道、（可选）调整优先级。复杂度在规划，不在操作。

**【建议】本地储备**
- 线路被切断时不会立刻停摆，而是先消耗储备。储备也能缓冲战斗时的消耗高峰。
- 给玩家留出反应时间，也制造"储备还能撑多久"的紧张感。

**【建议｜已实现·ADR 0025】节点血量分档**
| 血量 | 状态 |
|---|---|
| 高 | 正常运转 |
| 中 | 运力下降 |
| 低 | 严重受损，只能勉强维持 |
| 摧毁 | 节点消失，车辆和储备损失，留下废墟；下游只能靠各自的储备撑着（分档已实现·ADR 0025；被毁节点目前不留废墟【未实现】，可占领结构的废墟属占领机制，ADR 0038） |

**【建议】需要避免的坑**
1. **修复死循环**：受损的正好是负责送修复物资的节点。解决方式：修复物资由上游节点提供；或者由工程小队携带物资前去修复。
2. **崩溃螺旋**：受损 → 效率下降 → 资源变少 → 修不起 → 全面崩溃。保底手段：
   - 不受攻击时缓慢自我恢复，或者修复费用打折。
   - 主基地始终有一个基础能量产出，保证核心区域不断供。
   - 被摧毁的节点留下废墟，重建比新建便宜。（【已实现·M5】带 `capture` 档案的结构死亡生成无阵营废墟，占领后按纯时间重建，ADR 0038；通用节点修复仍未实现）
3. **全面连锁崩溃**：所有东西都依赖物流，系统统一的代价是出问题时会连锁。储备、优先级和清晰的可视化是关键。

**【建议】网络冗余**
- 腹地的跨方向连接让主线被切断时货物可以绕路送达，只是占用更多运力。
- 玩家需要决定：花资源铺冗余节点，还是全部投到前线。

**【建议】对怪物如何打击物流**
- 不打单辆运输车，而是**怪物停留在某段线路的走廊里时，这段运力下降或中断**；攻击补给站时降低其血量。
- 打击物流作为少数特定怪物（突袭类）的能力，而不是所有怪物都会这么做，避免玩家烦躁。

**【建议】双方规则对称**
- 怪物也有自己的物流网（题材上是蔓延的粘液地毯或发光根系），连接着巢穴和孵化点。
- 怪物的兵源和补给都来自它的据点网络。你每攻下一个点，它就实实在在弱一分。
- 切断怪物的补给脉络，前线的怪物就会衰弱。
- "先断补给、再总攻"会成为玩家自己发现的战术。

### 4.6 生产

**【已定】**
- 固定配方。
- 输入输出通过物流网连接中央仓库，没有传送带：投料从仓库运来，产品运回仓库，都占用线路配额（见 4.5）。
- 生产建筑要接入物流网并消耗能量才能运转。
- 发电厂产出能量，弹药厂产出弹药；矿机产出存在自身缓存里，运不回去时缓存满了就停工。

**【建议】给生产建筑的位置赋予意义**
没有传送带之后，生产建筑的位置容易变得无所谓，腹地变成点菜单。补救方式：
- 资源点只在特定位置。
- 生产建筑会被怪物攻击，需要防守。
- 相邻建筑有加成。
- 必须处于物流网服务范围之内；离仓库或主干越近，占用的运力越少（物流网本身已经把空间布局的意义带回来了）。

### 4.7 我方小队

**【已定】**
- 可以组建多个小队。
- 给小队分配指令，例如：在某个区域防守、沿某个方向进攻、填补前线等。

**【建议】**
- 指令式控制：只下粗粒度的指令，小队自己战斗。比 RTS 式微操轻得多，又比全自动更有参与感。
- 小队的价值在自由地图上更突出：去堵缺口、支援薄弱方向、攻占前哨。
- 小队需要补给：单位自带电池和弹匣，离开服务范围只能消耗自带的存量，推进太远会没电（见 4.5）。
- 工程小队可以负责修复补给节点。
- 突袭小队可以打击怪物的补给节点。

**【已落地 · M4】**（实现细节见 [ADR 0034](../adr/0034-squads.md)）
- 组建与指令：`Ctrl`+数字键把当前选中编成小队，数字键选中、双击聚焦；右键推进、Ctrl+右键驻守；`squads.set_strength` 调整编制，解散恢复散兵。
- 小队自行执行：驻守有交战半径与追击距离，推进到达自动转驻守，交战按武器实际够得着与否拆分停/走，低电量自动回补给覆盖充能后返岗，被堵路会攻障绕回。
- 补充：新单位自动补进缺口最大的小队。

**技术风险**：小队 AI（寻路、交战、执行指令）是整个项目最难做好的部分，原型阶段应该最先验证。

**【待定】**
- 兵种划分、更丰富的指令列表、嵌套编组。

### 4.8 防御建筑

**核心定位【建议】：用补给换兵力**
防御建筑不会走、不用指挥，能用较低的持续成本守住一片阵地。玩家只需要少量兵力就能守住一个方向，从而把主力小队集中到别处进攻（军事上的"兵力经济"原则）。

**攻守分工【建议】**
- 防御建筑是守住领地的骨架。
- 同时可以在新占领的区域修建，远程火力可以**支援小队进攻**，比如炮击覆盖敌方前哨。

**选址和形态【建议】**（基于自由寻路之后的调整）
- 从"覆盖路线"变成"控制区域、塑造战场"。
- 在控制区域、补给覆盖范围内的网格上自由摆放，**选址本身就是策略**：守隘口、占高地、护补给站。
- **墙和障碍物真正有意义**：可以改变怪物路线，把怪物引向火力区，或者迫使它们停下来攻击。
- 防线是一组建筑的组合（墙 + 火力 + 支援），形成有纵深的阵地，而不是一排零散的塔。
- 补给站本身就是防守重点。补给站放在哪，防御重心就在哪，建造、补给、防御在空间上绑在一起。

**和补给的关系【建议】**
- 建造需要材料，经物流网送达。
- 平时只有少量能量维护，**开火时消耗弹药（动能类）或能量（激光类）**。
- 安静的方向花费很少，激烈交战的方向会大量消耗补给，怪物反攻时前线补给压力自然暴涨。
- 有少量本地能量和弹药存储，补给断了还能顶一阵。

**和前线推进的关系【建议】**
- 只能建在自己控制、有补给覆盖的区域。
- 前线前推之后，后方建筑逐渐失去作用，这本身就是一种成本。允许拆除并回收部分资源，让玩家决定"留着防反扑，还是拆了往前搬"。
- 攻占敌方前哨时，原有的防御设施或许可以缴获、改造。
- 防御建筑被摧毁，前线就会后退。

**按功能分类【建议】**（只是大类方向，不是具体数值）
| 类别 | 作用 |
|---|---|
| 火力类 | 直射、范围、远程炮击；远程类可以支援进攻 |
| 阻滞类 | 墙、路障、雷区、减速区；改变或拖慢怪物路线 |
| 信息类 | 瞭望塔、雷达；驱散迷雾、预警集结 |
| 支援类 | 维修、增益、护盾 |
| 反制类 | 防空、反炮兵；针对特定怪物 |
| 驻防类 | 地堡、碉堡；小队进驻获得加成，**连接防御建筑和小队的桥梁** |

**需要注意【建议】**
- 龟缩刷塔：用开火消耗补给、建造空间有限、怪物随时间升级来制约。
- 防御建筑和小队互相抢戏：两者各有不可替代的价值，一个擅长守，一个擅长机动和攻占。
- 3D 下的可读性：射程、火力覆盖、补给覆盖都要清楚地显示在地面上。

### 4.9 阵营与对局模式

**【已定】**
- 当前版本只有**攻占模式**：敌方（怪物）开局时已经发育好，玩家从基础起步，推进并攻破要塞。参与方是我方、怪物、中立三方，中立方持有中立据点和资源点。（【已实现·M5】攻占/废墟/禁建区/迷雾已落地，ADR 0038/0039；当前版本据点全部开局归敌方，中立据点待讨论）
- 玩法可以随时增加或删除，架构不得成为阻碍（见 ADR 0019）。

**可能的方向（不是设计承诺，可能做，也可能删掉）**
- **PVP**：与其他玩家对抗。
- **对称 AI**：AI 和玩家用同一套规则从零发育，双方争夺中立资源和中立据点。
- **感染模式**：敌人是纯怪物，行为是扩散，成长线（科技线）的逻辑与攻占模式不同。

## 5. 题材与世界观

### 5.1 选题材的标准
1. 能解释机制：补给线、前线、攻占、攻破要塞、每局重开，在世界观里要说得通。
2. 敌我一眼可分：2D 和 3D 下都要读得清，敌我风格反差越大越好。
3. 有差异化：尽量避免和 Mindustry 撞车的"科幻机械殖民"。
4. 美术成本可控：风格化比写实更省力，也更耐看。

### 5.2 讨论过的方向
| 方向 | 优点 | 缺点 |
|---|---|---|
| 架空柴油朋克战争（一战风） | 铁路、战壕、重炮和补给机制完美贴合，有质感 | 人打人的写实题材多，沉重，敌我不好区分 |
| 微缩玩具战争 | 和 3D 移轴微缩观感很搭，轻松，辨识度高 | 紧张感和代入感偏弱，难撑剧情 |
| 菌丝或生物群落之战 | "网络即生命线"非常贴合，视觉独特 | 抽象，可读性和大众接受度有挑战 |
| 魔法奇幻 | 受众广，色彩丰富 | 魔法会削弱后勤的说服力 |
| 工业远征 vs 异种生物 | 补给、集结、对称网络、迷雾、Rogue 都说得通，敌我反差强 | 偏厚重 |

### 5.3 最终选择【已定】
**未来科技（大量机器人、无人机）对战怪物，偏轻松有趣。**

参照：《深岩银河》（打虫挖矿）、《幸福工厂》（FICSIT 公司的黑色幽默）、《致命公司》（为公司打工）、《皮克敏》《史莱姆牧场》（可爱生态）。

### 5.4 三个变体
| 变体 | 基调 | 评价 |
|---|---|---|
| **星际开荒公司** | 公司讽刺、黑色幽默 | **当前首选** |
| 机器人自治文明 | 温暖治愈，类似 WALL-E | 需要很强的叙事支撑；Rogue 的重复结构难以维持情感浓度；幽默感偏弱 |
| 家庭微缩战争 | 反差感 | 辨识度最高，但房间地形变化有限，撑不起大地图、长战线和多样的 Rogue 地图，更适合更小的游戏 |

### 5.5 星际开荒公司【建议，当前首选】
> 你是一家星际开荒公司的现场经理，指挥一群机器人员工，清理怪物横行的星球，好让公司把地卖给客户。

**选它的理由**
1. 和机制最贴合，几乎每个系统都有现成的解释。
2. 和地图结构最匹配：不同星球、不同生态天然提供大量地形和环境变化，支撑 Rogue 的多样性。
3. 幽默成本低：大量笑点可以靠文字实现（系统通知、合同条款、员工档案、KPI 报告），小团队也做得起。
4. 受众已经被验证过。
5. 进退都有余地：表面轻松，需要深度时可以往剧情里加料。

**机制的题材包装**
| 机制 | 包装 |
|---|---|
| 物流与补给 | 运输无人机把电池和弹药送到前线；机器人和无人机靠电池运转 |
| 补给站 | 充电中继站 |
| 运输车 / 运力 | 成群飞行的运输无人机 |
| 断补给 | 机器人没电，变慢、趴下、罢工 |
| 一局 | 一张合同：不同星球、不同怪物生态、不同客户要求 |
| 局内 / 局外奖励 | 公司发的奖金、新蓝图、员工福利 |
| 无限模式 | 加班 |
| 剧情模式 | 逐步揭开公司的秘密（可以埋反转：怪物其实是原住民，公司才是反派） |
| 迷雾 | 孢子雾、未勘探区域 |
| 敌方补给网 | 蔓延的粘液地毯或发光根系 |
| 敌军要塞 | 巨大的巢母或女王，打到最后会变形 |

**怪物设计方向**
- 可爱又怪：色彩鲜艳、圆滚滚、果冻质感的生物生态。
- 行为有趣：成群推挤、叠罗汉翻墙、吃掉建筑之后打个嗝。
- **怪物是真正的差异化所在**，值得投入最多心思。

**幽默来源**
- 公司系统通知："本季度 KPI 未达标""员工 #4032 已离职（被吃掉）""客户投诉：草坪不够平"。
- 机器人有个性和语音，小队可以起名字。
- 夸张的物理表现：机器人被打飞、无人机撞成一团。

**视觉风格**
- 卡通渲染或干净的低多边形，明亮配色。
- 我方：白、蓝、橙等干净的工业色。
- 怪物：紫、绿、粉等饱和的有机色。
- 从家庭微缩方向借视觉质感：3D 观战时带一点移轴和模型感。
- 从自治文明方向借机器人个性：让玩家对小队产生感情，机器人被吃掉时又好笑又心疼。

**风险**
- 公司讽刺这个梗已经有人做过（FICSIT、深岩银河），要有自己的声音。
- 讽刺要荒诞好笑，不要变成刻薄阴暗。
- 机器人容易千篇一律，差异化要靠怪物生态。
- 未来科技 + 机器人在风格上容易和 Mindustry 撞车，差异化要靠调性和怪物设计。

## 7. 风险汇总

1. **复杂度失控**：每加一个东西都要问：它有没有让核心循环更好？
2. **小队 AI**：寻路、交战、执行指令是技术难度最高的部分。
3. **大量单位自由寻路的性能**：需要流场寻路（flow field）一类的方案，不能每个单位单独跑 A*。原型阶段要验证。
4. **补给系统的透明度**：必须充分可视化，否则会变成 HOI4 那样让人看不懂。
5. **滚雪球与崩溃螺旋**：靠补给的距离损耗、本地储备、保底恢复和导演系统来调节。
6. **敌人路线的可预测性**：自由寻路之后更难预测，需要预计路线可视化。
7. **3D 美术投入被浪费**：要让 3D 视图也能操作、有信息，并且和 2D 视图无缝过渡。
8. **UI 与信息量**：多方向、多小队、补给、生产同时进行，信息层设计是体验好坏的分水岭。
9. **工作量**：系统数量多于纯塔防，范围要严格控制。
10. **与 Mindustry 的差异化**：靠攻守转换、补给网络主轴、题材调性和怪物生态来拉开。

## 8. 待定问题

1. **局外模式**：无限模式、剧情模式，还是两者都有？
2. **小队系统细节**：兵种怎么分、指令有哪些、小队如何组建和补充。指令、组建与补充已定（驻守 / 推进 / 集结，工厂自动补缺编最多的小队，ADR 0034）；小队会混编多种单位（负责人已定，2026-11-22；寻路已按 1×1 / 2×2 两档净空与混编小队实现，ADR 0052、0059）；具体兵种划分未定，原型只有一种机器人。
3. **怪物生态的设计思路**：差异化的核心，下一步优先讨论。仍未讨论；原型只有 crawler / spitter / raider 三种占位怪物。
4. **敌人是否有可见的资源和兵源**：倾向于做成与玩家对称的据点 + 物流网，需要最终确认。现状：敌方有据点与巢穴（ADR 0038），没有物流网；是否对称仍未确认。
5. **打击物流的怪物范围**：倾向于只有少数突袭类怪物具备这个能力。现状与倾向一致：只有 raider 带走廊拦截（ADR 0030）。
6. **防御建筑是否在开火时消耗补给**：已定，开火消耗弹药或能量（见 4.5、ADR 0025）。
7. **镜头的具体切换方式**：已定（ADR 0028，经 ADR 0048 更新）：`Tab` 切换、400 ms 过渡且画面不跳；取消暂停自动切视角，改为未开启「视角锁定」时进入 `F2` 建造 / `F3` 物流自动切至 2D 战术视角、返回 `F1` 自动恢复 3D。
8. **目标平台**：已定，只做 PC 键鼠单机，不做触屏（architecture.md §3.2）。
9. **引擎与团队规模**：已定，网页技术栈（TypeScript + React + three，ADR 0003），开源小团队（architecture.md §2）。
10. **敌方是否对称接入补给网**：§4.5 把"怪物的补给网，先断补给再总攻"当作核心战术；原型里巢穴免费产兵（`inputs: {}`），怪物不消耗能量弹药，丢失据点也不削弱巢穴。攻占模式是否需要敌方补给网，还是留给将来的对称模式？
11. **成长主轴**：§4.3 主打局内 Rogue（攻占拿蓝图/藏品）；设计清单 A2（ADR 0033）倾向打完一关拿科技点、跨局解锁科技树。主驱动力偏哪一边？
12. **规模与题材表现**：设计清单 D16 按千级以上单位考虑；§5.5 强调给小队起名、机器人有个性。体验重心偏大兵团调度，还是几十到上百个有个性的机器人？
13. **主动拆除返还比例**：设计清单 D4 倾向返还 100% 造价、只耗工时；§4.8 写"部分资源"；原型 `salvageBp = 5000`（50%）。
14. **城墙诱导寻路与高度规则的优先级**：§4.1/§4.8 强调城墙改道、高地加视野射程；原型没有城墙或阻滞建筑，高度也不影响战斗。它们是验证核心循环的必需件，还是放进内容扩充期？
15. **原型之后的重心**：先做一轮可玩性打磨（兵种、城墙、据点差异、数值），还是先以当前底座做团队评审？

### 9.2 最小原型（最初的建议，已由实际原型取代）
以下是原型开工前的建议，保留作为讨论记录。实际原型与它的差异：3D 观战与 2D 指挥一开始就同时做了；防御建筑只有一种基础炮塔；小队只有一种机器人；据点只有一种。

目标：验证"守、推、占"加补给的核心循环在约 30 分钟里是否好玩，并尽早验证技术难点。

建议范围：
- 1 张地图，2 个进攻方向，若干关键地形（隘口、不可通行区、减速区）。
- 中央仓库 + 补给站，实现"连通 + 运力 + 本地储备 + 节点血量"。
- 2–3 个固定配方的生产建筑。
- 3 种防御建筑（例如火力、阻滞、信息各一）。
- 2 种小队，支持区域防守、沿方向进攻两个指令。
- 3 种前哨或资源点，以及战争迷雾。
- 简单的导演系统：集结 → 可见预警 → 反攻。
- 1 座敌军要塞。
- 暂停与调速。
- 灰盒美术，先只做 2D 战术视图，3D 观战之后再加。

原型阶段最先验证的东西：
1. 大量单位自由寻路的性能（流场寻路）。
2. 小队 AI 执行指令的可靠性。
3. 物流网的状态（瓶颈、缺货原因）是否一眼能看懂。
4. 核心循环在 10 分钟内是否已经有乐趣。如果没有，后面堆内容也救不回来。
