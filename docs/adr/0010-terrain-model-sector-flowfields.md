# 0010. 地形模型与分区流场

- 状态：已采纳
- 日期：2026-11-14
- 决策者：wislap
- 批次：M0 架构基线
- 领域：地形

## 背景

地形不是平面：有空中层、城墙、高地，将来可能有海域、悬崖等；高度进入规则（视线、射程修正），不只是视觉。需要支撑大量单位自由寻路（[architecture.md §3.4、§1.3](../design/architecture.md)）。

## 决策

- **格子**：高度层级（整数）、地表类型（陆地、浅水、深水……）、地表修正（减速等）。城墙不是地形，是占格建筑。
- **边**：相邻格是否可通行。悬崖 = 不同高度层级之间的边不可通行（坡道例外）。
- **移动类别**：地面、两栖、海上（以后）、空中……每类一张代价表。寻路按「移动类别 × 体积等级」生成代价场。特殊怪物（如翻墙）通过代价表或"攻击障碍"逻辑表达。
- 视线、射程修正、空地目标可攻击性读取同一张高度网格。
- 只有地形模块知道原始地形编码；其他模块通过其公开的格子 / 边属性与代价场读取。新增地表类型 ≈ 新增类型 + 代价表数据，不改寻路算法。
- 流场按扇区缓存；建造或摧毁阻挡物时只失效受影响扇区，局部重算。
- 流场之上需要局部避让（分离与推挤），邻居遍历顺序必须确定。

### 待定事项

- 具体规模数值（地图格数、单位上限）：随地图设计确定，先按上限设计（[§13](../design/architecture.md)）。

## 后果

- 分区流场 + 局部避让是性能热点，从第一天就位；其余按实测优化（[§14](../design/architecture.md)）。
