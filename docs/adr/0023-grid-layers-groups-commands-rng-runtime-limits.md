# 0023. 网格图层、编组、命令 schema、RNG 登记与运行时限制

- 状态：已采纳
- 实现：部分（缺：经济收入来源注册接口、MatchSetup 开局修正值与局外进度前端占位未做）
- 日期：2026-11-15
- 决策者：wislap
- 批次：M1 前置
- 领域：架构

## 背景

团队的《设计决策清单 v2》（2026-11-15，非正式需求）讨论到的若干方向会影响架构：按格子状态计收入与地块污染（A1、A2）、全局千级单位与多层编组（D16）、将来的自然语言指令（A6 不进 MVP 的 Yui 指令）、随机只在选项里（D10）、拆除返还造价并消耗工时（D4）、局外科技（A2）、插件市场的包体积与运行时下载规则（D21）。

## 决策

### 网格图层
- 同一张网格上叠加多层数据：地形、补给覆盖、迷雾、将来的污染度、影响范围等。kernel 提供统一的网格图层机制，**每一层只由一个模块写入**（[ADR 0008](0008-module-collaboration.md) 单一写者）。
- 属于某一方的图层按 `FactionId` 分开（[ADR 0019](0019-factions-and-pluggable-modes.md)）。
- 快照中每层一个通道，只在变化时发送。
- 按图层状态的统计（例如"未感染格子数"）由图层所有者增量维护，不在每个 tick 全图扫描。

### 编组层级
- 编组可以嵌套：单位属于小队，小队可以属于更大的编组；命令可以下达给任意一层编组。
- 编组是小队模块中的数据（[ADR 0009](0009-partial-ecs-boundary.md)、[ADR 0021](0021-scheduled-effects-entity-relations.md)），M4 落地。

### 收入来源
- 经济模块只开放"注册收入来源"接口，收入公式写成具名行为，由玩法或规则原型选择（按时间、按格子数等），不写死在经济模块里。不另外搭框架。

### 命令 schema
- 每种命令有唯一的 schema 来源，TS 类型、运行时校验、命令索引都由它派生。
- 来自不可信来源的命令（宿主桥接、回放文件、将来的远端玩家与自然语言指令）在进入模拟前做运行时校验，再做发出者权限校验（ADR 0019）。
- 具体实现方式（自写或引入库）在 M1 说明理由后选定。

### RNG 用途登记
- 所有 RNG 流在 `app/` 中集中声明用途，新增一条流会在 diff 中显眼地出现，便于评审。
- 只做登记，不禁止任何模块使用 RNG："随机只在选项里"是可能变化的设计决定，不写成架构限制。

### 拆除
- 拆除复用建造的进度机制（[ADR 0012](0012-construction-as-entity.md)），与建造、修复、升级同一套；返还比例与工时是内容数据。

### 局外
- 原型不做玩家档案持久化与跨版本迁移，留到正式版之前再考虑。
- 局外的效果只通过 MatchSetup 进入对局（解锁清单与开局修正值，[ADR 0022](0022-match-setup-content-ids-packs.md)），模拟层不知道局外存在。原型的局外只做占位与前端演示，数据在内存中。

### 运行时网络与包体积（插件市场规则）
- `static/` 总体积 ≤ 32MiB，超过 24MiB 时 CI 预警。
- 禁止在运行时下载或执行代码：`eval`、`new Function`、远程 URL 的动态 `import()` 由 lint 禁止。
- 只有资源加载模块与 `host/` 可以访问网络（lint 限制 `fetch` 等的使用位置）。将来运行时下载的 3D 素材必须登记在资源清单中，带固定版本与 SHA-256，加载时校验，并在 README 写明域名、用途、时机、大小；清单格式届时再定。

## 后果

- 新增一种地面信息（污染、影响力）= 新增一个图层 + 所有者模块，不改其他图层。
- 命令可以安全地来自任何来源，代价是每种命令都要写 schema。
- 包体积与网络规则在 M1 即由 CI 与 lint 强制。
