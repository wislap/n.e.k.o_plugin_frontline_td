# 0005. 固定步长 20Hz、变速与暂停

- 状态：已采纳
- 实现：已实现
- 日期：2026-11-14
- 决策者：wislap
- 批次：M0 架构基线
- 领域：模拟

## 背景

确定性模拟要求固定步长；玩家需要变速与暂停来掌控大规模战局（[architecture.md §3.3](../design/architecture.md)）。

## 决策

- 固定步长：每 tick 推进 50ms 模拟时间，1x = 20Hz。
- 变速只改每秒 tick 数，不改每 tick 时长；倍速档位初始为 `[0, 1, 2, 3]`，以配置数组定义；必须支持暂停。
- 每个真实时间片最多补跑 N 个 tick，超出部分丢弃（游戏变慢，避免死亡螺旋）；调试面板显示实际 tick 速率。
- 模拟逻辑不依赖帧时间差（[§9](../design/architecture.md)）。
- 暂停与变速是运行时状态，不进命令日志，因为它们不影响游戏结果（[§6.5](../design/architecture.md)）。

## 后果

- 高倍速下性能不足表现为游戏变慢而非跳帧，行为可预期。
- 命令日志 + 种子即可复现一局，支撑确定性测试（[ADR 0006](0006-determinism.md)）。
