# 0011. 弹道与效果的组合模型

- 状态：已采纳
- 实现：部分（缺：仅 instant 交付与单体伤害；追踪/抛物线投送、地面/区域目标选择与范围/状态效果包未做）
- 日期：2026-11-14
- 决策者：wislap
- 批次：M0 架构基线
- 领域：战斗

## 背景

弹道类型多样（光束、延迟但必定命中、范围炮击等），不能写死为枚举（[architecture.md §3.5](../design/architecture.md)）。

## 决策

武器 = 正交维度的数据组合（[§6.9](../design/architecture.md)）：

- 投送方式：即时 / 光束、追踪且必中（有飞行时间）、抛物线打地面……
- 目标选择：单位、地面点、区域。
- 效果包：伤害类型、范围形状、持续伤害 / 状态效果。

新武器 = 新数据组合；只有新投送方式才需要在战斗模块新增系统。

## 后果

- 加武器多数情况下只加 `content/` 数据（[§7.4](../design/architecture.md)）。
- 新增投送方式是代码改动，但按维度正交，影响局部。
